PC-TALKER for NVDA

This add-on speaks with PC-TALKER 5.01, the Hungarian speech synthesizer written by Király József and released in 1991. This is the Sound Blaster version; the program was distributed at the time by Technorecord, Műszertechnika, and later SZKI Recognita Rt.

The voice is not an imitation and not a reimplementation: the original 1991 program runs, instruction by instruction, inside NVDA. Its speech elements were cut from 8 kHz recordings of Király József's own voice, made in 1987, so the voice you hear is his.

Two voices

Version 2.0 adds a second engine. Both are selectable in NVDA's voice list, and both are Király József's own software running instruction by instruction — no DOSBox, no external program.

SPEAKER 1.0 (1990) — PC speaker (default)
The build for a machine with no sound card at all. Amplitude becomes pulse width on channel 2 of the 8253 timer, at 18356 Hz. It is the cleaner of the two by ear, because it has no smoothing stage joining its speech elements and therefore no echo. The program that runs here is the original OLVASSP.EXE, dated 27 January 1991; its banner reads PC-TALKER Beszédszintetizátor / SPEAKER_ v. 1.0, Copyright 1990, and the recordings it is assembled from are dated 1989. It was never commercially released.
PC-TALKER 5.01 (1991) — Sound Blaster
The version described below, run from a memory image of the resident driver. Slightly warmer, with a faint room echo that comes from the stage that smooths between its concatenated voice elements.

There is no reverb control. The 1991 manual documents a #vnnnn command, and it does change the output — but it only ever adds delay on top of the echo that is already there, so no setting of it can produce a dry voice. That is why SPEAKER is the default.

How it works

  1. Memory image. The OLVRES resident program is loaded under DOSBox, made to speak one line so all initialisation has happened, and then the whole 640 KB of conventional memory is dumped to a file (engine.bin). In that image the TSR is already resident and ready to be called.
  2. Emulation. The add-on executes that image with the Unicorn CPU emulator, in 16-bit real mode, inside NVDA's own process. No DOSBox, no DOS, no external program. The image is mapped at linear address zero so every far pointer inside it stays valid.
  3. Calling it. NVDA addresses the engine exactly as the original OLVIT utility did. The INT F1h vector is read out of the memory image itself, then:
    AH = 0    ES:DI → text    CX = length    INT F1h
    The engine copies the text into its own data segment and clamps it at 255 characters, so the add-on splits longer text into smaller pieces.
  4. Audio. The AH = 0 call does not synthesize. It queues the utterance, reprograms PIT channel 0, and returns. The audio is then produced by the INT 8 timer interrupt, one byte per tick written to the Sound Blaster's direct DAC (DSP command 10h). The engine uses no DMA at all. The add-on therefore pumps the INT 8 handler in a loop and collects the samples it writes.
  5. Sample rate. This did not have to be guessed: the divisor written to port 40h gives it. 1193181.666 / 130 = 9178 Hz, resampled to 22050 Hz for NVDA's audio output.

Rendering runs about five times faster than real time, and the first sample appears on the very first timer tick, so speech starts without delay.

Settings

  • Rate. The engine has no speed control of its own — AH = 1..4 are stop, continue, restore-timer and query — so rate is applied by resampling. Pitch moves with it, like the speed control on a tape machine. The midpoint, 50, reproduces the engine exactly.
  • Volume. Applied to the output.

What is inside the package

NVDA add-ons are ordinary ZIP archives. With no NVDA installed, just rename the file to .zip and any archiver will open it. Inside:

  • manifest.ini — add-on metadata
  • synthDrivers/pctalker.py — the NVDA driver
  • synthDrivers/_pctalker_engine/pctalker_core.py — the emulation core
  • synthDrivers/_pctalker_engine/engine.bin — the 640 KB memory image
  • synthDrivers/_pctalker_engine/lib/unicorn/ — the Unicorn emulator
