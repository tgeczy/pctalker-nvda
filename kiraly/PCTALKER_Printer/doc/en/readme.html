PCTALKER Printer version - Hungarian - DEMO

This addon demonstrates the audio quality of the Hungarian PCTALKER Printer version developed by J. Kiraly between 1989 and 1991.

Character encoding

Version 0.1.5 uses CWI-2 / CP-HU instead of CP852. For historical table compatibility, Ó, Ú, Ő and Í are mapped to ó, ú, ő and í before CWI-2 encoding.

Audio path

The original DOS version sent multi-level sample values to an external D/A converter connected to the printer port. This add-on reconstructs the same speech data as 8-bit mono PCM at 8,500 Hz and sends it to NVDA WavePlayer.
