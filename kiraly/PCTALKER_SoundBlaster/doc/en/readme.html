PCTALKER Sound Blaster version - Hungarian - DEMO

This addon demonstrates the audio quality, improved intonation and echo capability of the Hungarian PCTALKER Sound Blaster version developed by J. Kiraly in 1991.

The historical OLVAS_S.ASM identifies the software as PC-TALKER Sound-Blaster version 5.01, last updated 13 January 1991.

NVDA settings include Rate and Echo delay (samples). Echo defaults to 250 samples; zero disables echo in this reconstruction.
